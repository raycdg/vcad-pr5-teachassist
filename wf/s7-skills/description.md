# Практическая работа по автоматизации работы с агентом

## Контекст

Практическое задание раздела 6.2 подразумевает создание хука в Claude.
Я использую не Claude, а OpenCode, поэтому в этой работе сделаем скил для него.
Скилы - это тоже средства автоматизации для агента, подробнее про скилы в OpenCode:
<https://opencode.ai/docs/skills/>

## Задача

Сделаем скил для анализа покрытия тестами проекта.
Задачи скила:

- запустить тесты и проверить покрытие кода тестами;
- проанализировать покрытие, найти какие файлы и методы покрыты тестами;
- оценить качество этого покрытия (хорошо, средне, плохо);
- найти непокрытые участки кода;
- оценить непокрытый код и дать оценку приоритетности его покрытия (срочно, не срочно, в последнюю очередь);
- составить отчет

## Реализация

Скил размещен в папке проекта:
.opencode/skills/test-coverage

## Проверка

Для проверки был дан следующий промпт:

```text
Проанализируй покрытие тестами backend
```

wf/s7-skills/test-report.md
