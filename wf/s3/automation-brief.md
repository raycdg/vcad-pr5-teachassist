## Тип задачи
Одноразовый служебный скрипт, язык JavaScript, NodeJS

## Цель
Загрузить из файла в формате Excel (xlsx) список студентов и добавить к заданной группе

## Входы
Входные параметры:
- путь и название файла с расширением xlsx, пример файла wf/s3/test-students.xlsx 
- идентификатор группы, в которую добавить студентов
- режим запуска `dry-run` (по умолчанию) или `apply`
- параметры для подключения в БД нужно взять из `backend/appsettinfs.json`

## Выходы
Изменения в БД:
- новые студенты мз файла добавляются к группе
- для существующих студентов обновляется email (условие поиска: совпадение имени и фамилии без учета регистра)
Лог операции:
- сколько студентов прочитано из файла
- сколько добавлено
- сколько обновлено
- ошибки, если есть

## Побочные эффекты
- Изменяется только информация в таблице студентов группы, другие данные не затрагиваются;
- Лог выводится в консоль и сохраняется в файл с именем текущей даты/времени + `.log`

## Безопасность запуска
- по умолчанию скрипт запускается в режиме `--dry-run`
- изменения в БД делаются только при указании флага `--apply`
- обеспечивается идемпотентность запуска
