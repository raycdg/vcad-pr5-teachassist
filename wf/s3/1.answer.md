# Ответ агента

Готово. Вот результат:

**Изменённые файлы:**
- `scripts/import-students/import.js` — основной скрипт
- `scripts/import-students/package.json` — зависимости (xlsx, pg)
- `scripts/import-students/.gitignore` — игнор node_modules и логов

**Команда запуска:**
```bash
cd scripts/import-students
node import.js --file путь_к_xlsx --group ID_группы [--dry-run|--apply]
```

**Ограничения:**
- Скрипт не создаёт группу, если ID не существует
- По умолчанию `--dry-run` (без изменений в БД)
- Для подключения к БД используется `backend/appsettings.json`
- Структура xlsx: колонки `First Name`, `Last name`, `Email` (регистр неважен)
- Лог сохраняется в файл с временной меткой в папке скрипта
