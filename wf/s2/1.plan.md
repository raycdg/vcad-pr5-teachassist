Обновлённый план с учётом уточнений:

### 1. Конфигурация
- Добавить секцию `Smtp` в `appsettings.json` (Host, Port, EnableSsl, Username, Password, FromEmail, FromName)
- Создать POCO `SmtpOptions` для биндинга

### 2. Файловый логгер
- Поскольку официального пакета `Microsoft.Extensions.Logging.File` не существует, создам минимальный `FileLoggerProvider` (реализация `ILoggerProvider`), пишущий в `backend/grade-notifications.log`
- Зарегистрирую через `builder.Logging.AddProvider(...)`

### 3. Адаптер `backend/Api/Services/GradeNotificationAdapter.cs`
- Конструктор: `SmtpOptions`, `ILogger<GradeNotificationAdapter>`, `DomainDbContext`
- Метод `NotifyGradesSavedAsync(int courseId, IEnumerable<GradeEntryDto> grades, CancellationToken ct)`:
  - Группирует оценки по `StudentId`
  - Загружает данные студентов, курса, дисциплины, заданий
  - Тема: `Выставлены оценки по предмету {Discipline.Abbreviation}`
  - Тело: HTML, приветствие по имени/фамилии, дата в `DateTime.Now` с локальным форматом, таблица заданий/оценок
  - `SmtpClient.SendMailAsync` — fire-and-forget (без await в контроллере)
- Обработка ошибок (лог + проглатывание):
  - Нет настроек SMTP → Warning
  - Нет/невалидный email → Warning, пропуск студента
  - `SmtpException` (timeout, network) → Error

### 4. DI (Program.cs)
- Биндинг `SmtpOptions`
- Регистрация `FileLoggerProvider`
- Регистрация адаптера как scoped

### 5. Точка интеграции: `CoursesController.SaveGrades`
- Инжект `GradeNotificationAdapter`
- После `SaveChangesAsync()` — вызов `adapter.NotifyGradesSavedAsync(...)` **без await**

### 6. Тесты `backend/Api.Tests/GradeNotificationAdapterTests.cs`
3 интеграционных теста (smtpbucket.com:8025):
- Успешная отправка (проверка: не выбрасывает)
- Несуществующий хост (проверка: ошибка в логе, исключение не пробрасывается)
- Невалидный email (проверка: студент пропущен)
