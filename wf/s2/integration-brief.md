# Integration brief

## Сценарий
При сохранении преподавателем оценок студентам отправляется письмо на email с перечислением какую оценку за какое задание ему поставили

## Контракт
- используем функционал библиотеки network из dotnet
- входные данные: email студента, оценки из StudentGrade
- отправка асинхронно, без задержки отклика API
- содержание письма: уважительная форма обращения с использованием имени и фамилии, информация о дате/времени события, по какому предмету, перечисление таблицей по какми заданиям и какие оценки были поставлены; тема письма: Выставлены оценки по предмету {сокращение предмета}

## Конфигурация
- параметры подключения к почтовому серверу храним в appsettings.json

## Ошибки и ограничения
- отсутствие настроек подключения к почтовому серверу
- отсутствие email у студента или неверный email
- таймаут или сетевой сбой

## Логирование и обратная связь
- успешные и неуспешные отправки сохранять в текстовый лог в текущей папке backend, не сохранять credentials
- пользователь не уведомляется о неуспешной отправке уведомлений в UI

## Тестирование
- для тестирования интеграции используем сервис www.smtpbucket.com
- параметры отправки писем:
    - адрес сервера: mail.smtpbucket.com
    - порт: 8025
    - авторизация отсутствует
- создать один успешный тест с успешной отправкой письма на mail.smtpbucket.com (проверяется только факт успешной отправки), создать неуспешные тесты с неверными настройками (не найден почтовый сервер), с некорректным почтовым адресом (отказ от сервера принять письмо)

## Не входит в проход
- уведомление в системе
- уведомление другими способами
- контроль получения уведомления студентом

## Критерии готовности
- тесты проходят
- ручная проверка проставления оценки студенту, на сервисе www.smtpbucket.com должно найтись отправленное письмо
