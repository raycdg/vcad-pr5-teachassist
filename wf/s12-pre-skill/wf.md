# Практическое задание 7.2: опишите контракт будущего skill

## Шаг 1. Выберите узкий сценарий

На прошлом задании был сформирован перечени вариантов повторяющихся рабочих сценарев. наиболее подходящим для формирования будущего skill можно из них взять: `W2. Исправление багов с проверкой (fix + verify)`.

## Шаг 2. Заполните контракт

Даем запрос агенту:

```text
Прочитай @wf/s11-reuse/reusable-workflows.md (сценарий W2)
Задача: создать контракт будущего skill в файле wf/s12-pre-skill/bugfix-n-verify-contract.md

Заполни поля:
- Название skill
- Назначение
- Когда применять / когда не применять
- Входы
- Ожидаемый результат
- Основные шаги
- Стоп-сигналы
- Вспомогательные материалы
- Критерии приёмки
- Открытые сомнения

Не меняй код и схему БД. Только документ.
```

Ответ от агента:

```text
Файл `wf/s12-pre-skill/bugfix-n-verify-contract.md` создан. Заполнены все поля на основе сценария W2:

- **Название**: Bugfix & Verify
- **Назначение**: автоматизация цикла fix → verify → acceptance
- **Когда применять / не применять**: баги, исключения, N+1, warnings; не для новых фич, рефакторинга, миграций
- **Входы**: описание проблемы, затронутые файлы, тесты, контекст
- **Ожидаемый результат**: исправленный код, пройденные проверки (build/test/lint), совместимость API
- **Основные шаги**: 9 шагов от локализации до подтверждения commit
- **Стоп-сигналы**: изменения миграций, публичных API, нарушение AGENTS.md
- **Вспомогательные материалы**: AGENTS.md, docs, команды, стек
- **Критерии приёмки**: checklist из 9 пунктов
- **Открытые сомнения**: 5 вопросов для уточнения
```

## Шаг 3. Проверьте границы

Контракт skill не пересекается с постояннымим правилами проекта, а следует им.

## Шаг 4. Попросите агента выступить ревьюером контракта

Даем запрос агенту:

```text
Проверь контракт будущего skill как строгий reviewer.
Найди:
- слишком широкий триггер применения;
- дублирование project rules;
- скрытую автоматизацию спорных решений;
- слабые критерии приёмки;
- стоп-сигналы, которые стоит сделать явнее.
Не переписывай контракт сразу. Верни замечания списком и предложи, какие поля нужно уточнить.
```

Ответ сохранен в skill-contract-review.md

## Шаг 5. Обновите контракт и оставьте передачу в 7.3

Даем запрос агенту:

```text
Внеси исправления в контракт в соответствии с review и сохрани в новый файл `wf/s12-pre-skill/bugfix-n-verify-contract-fixed.md`
После дай короткий handoff в `wf/s12-pre-skill/bugfix-n-verify-handoff.md`. handoff должен включать:
- Сценарий для SKILL.md
- Входы, которые должны быть доступны агенту
- Ожидаемый результат
- Стоп-сигналы
- Материал, который возможно понадобится
- Открытые сомнения перед реализацией
```
