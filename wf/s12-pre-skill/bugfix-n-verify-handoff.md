# Handoff: Bugfix & Verify skill

> Готов к упаковке в SKILL.md | Дата: 2026-05-05

---

## Сценарий для SKILL.md

```
Название: Bugfix & Verify
Trigger: Пользователь сообщает о баге, ошибке, warning, failing test или UI-проблеме
Workflow: pre-flight → локализация → проверка покрытия тестами → анализ причины → исправление → build → test → lint → стоп-сигналы → документация → подтверждение commit
```

## Входы (должны быть доступны агенту)

| Вход | Источник | Формат |
|------|----------|--------|
| Описание проблемы | Сообщение пользователя | Текст, stack trace, лог |
| Контекст | Сообщение пользователя | Endpoint, страница, данные |
| Файлы проекта | Файловая система | `backend/`, `frontend/` |
| Тесты | `tests/TeachAssist.Api.Tests/` | xUnit тесты |
| Ограничения проекта | `AGENTS.md` | Правила и запреты |
| Документация | `docs/README.md` | Описание функционала |

## Ожидаемый результат

- Исправленный код (не более 3 файлов)
- Прошедшие `dotnet build`, `dotnet test`, `npm run lint` (если frontend)
- Подтверждённая API-совместимость через `git diff` контроллеров/DTO
- Явное подтверждение пользователя перед commit

## Стоп-сигналы

| Сигнал | Условие | Перенаправление |
|--------|---------|-----------------|
| Миграции БД | Требуется изменение `backend/migrations/` | Запрос разрешения |
| Контракт API | Изменение DTO, HTTP-статусов, сигнатуры | Запрос разрешения |
| > 3 файлов | Затронуто более 3 файлов | W1 (long-horizon) |
| > 2 итераций | Не удалось исправить за 2 попытки | W1 (long-horizon) |
| Структура тестов | Требуется изменить тесты | W6 |
| Нет тестов | Область не покрыта | Предупреждение + W6 |
| Визуальная полировка | Ошибка не подтверждена, только «не нравится» | W7 |
| Новая функциональность | Требуется новый endpoint или бизнес-правило | W3 или W1 |
