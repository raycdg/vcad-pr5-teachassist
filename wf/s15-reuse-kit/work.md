# Практика 7.5: соберите первый agent workflow kit

## Agent workflow kit plan

Будем делать kit для задач debug & fix. Нам нужно составлять debugging brief, исправлять проблему, проверять решение, делать ревью на diff.
Прикинем состав нашего kit:

|Сценарий | Режим автономности | Что запускать | Как принять | Когда остановиться
|------|-----------|-----------|-----------|-----------
|Debugging brief | read-first | debug-brief template | гипотезы и следующие проверки | агент предлагает fix без причины
|Bugfix checklist | read-only | checklist-results | условия чеклиста выполнены | есть нарушения ограничений
|Buffix + verify | read-first | Buffix-n-verify skill | исправлена первопричина проблема, тесты проходят | выход за пределы границ задачи
|Review AI-diff | read-only / local diff | команда /review-diff | блокирующие замечания отдельно | выход за пределы границ задачи

## Личное / проектное

Что из этого можно сделать личным, а что останется только проектым:

|Сценарий | Личное/проектное | Почему
|------|-----------|-------
|Debugging brief | Личное/Проектное | Достаточно универсальный патерн для широкого класса проектов
|Bugfix checklist | Проектное | Сильно зависит от правил проекта
|Buffix + verify | Проектное | Сильно зависит от правил проекта
|Review AI-diff | Личное/Проектное | Достаточно универсальный патерн для широкого класса проектов

## Проверка kit агентом

Выполним запрос:

```text
Проверь мой agent workflow kit wf\s15-reuse-kit\agent-workflow-kit-ai.md

Найди:
- дублирование между rules, skills, commands и templates;
- элементы без понятного сценария применения;
- слишком широкие команды;
- skills без стоп-сигналов;
- чеклисты, которые не проверяют результат;
- места, где нужен ранний возврат человека в цикл.

Не редактируй файлы сразу. Сначала верни список замечаний и предложи минимальные исправления.
```
