## 1. Точки встраивания

- **Маршрутизация**: `frontend/src/router/index.js` — добавить два новых маршрута для страниц управления преподавателями
- **Disciplines.vue**: добавить переход к управлению преподавателями дисциплины (кнопка в таблице)
- **Courses.vue**: добавить переход к управлению преподавателями курса
- **API**: использовать существующие эндпоинты бэкенда (назначение/снятие)

## 2. Файлы для реализации

**Создать:**
- `frontend/src/views/DisciplineTeachers.vue` — просмотр и управление преподавателями дисциплины
- `frontend/src/views/CourseTeachers.vue` — просмотр и управление преподавателями курса

**Изменить:**
- `frontend/src/router/index.js` — добавить маршруты `/disciplines/:id/teachers` и `/courses/:id/teachers`
- `frontend/src/views/Disciplines.vue` — добавить для дисциплины кнопку перехода к управлению преподавателями
- `frontend/src/views/Courses.vue` — добавить для курса кнопку перехода к управлению преподавателями

**Опционально (если потребуется кэш списка преподавателей):**
- `frontend/src/stores/teachers.js` — хранилище Pinia для списка преподавателей

## 3. План реализации

1. **Маршруты**: добавить в `router/index.js` два маршрута с `meta: { requiresManager: true }`
2. **DisciplineTeachers.vue**: таблица назначенных преподавателей + диалог добавления (выбор из списка) + кнопка удаления. Использовать `GET /api/disciplines/{id}` для данных и `POST/DELETE` для назначения/снятия
3. **CourseTeachers.vue**: аналогично для курсов
4. **Навигация**: в `Disciplines.vue` и `Courses.vue` добавить кнопку "Преподаватели" в строку таблицы
5. **Список преподавателей**: использовать `GET /api/users` (или существующий механизм) для получения списка доступных преподавателей при назначении
6. **Проверка**: `npm run lint` в `frontend/`, убедиться что существующие тесты зеленые

## 4. Риски расползания scope

- **Доработка API на бэкенде** — если нет эндпоинта получения списка преподавателей дисциплины/курса (проверить, возвращает ли GET дисциплины/курса список преподавателей)
- **Создание новых store** — можно обойтись прямыми вызовами API из страниц
- **Редактирование App.vue** — не нужно, навигация со страниц дисциплин/курсов достаточна
- **Права доступа к списку пользователей** — `GET /api/users` требует Admin, менеджеру может не хватить прав (риск доработки бэкенда)
- **Добавление поиска/фильтрации** — не входит в скоуп, использовать базовую таблицу Vuetify
