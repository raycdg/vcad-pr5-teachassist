### Типы предупреждений (в порядке возрастания стоимости устранения)

#### 1. **CS8604: Возможно, аргумент-ссылка, допускающий значение NULL**
- **Суть:** Передача потенциально null-параметра в метод, ожидающий не-nullable ссылочный тип.
- **Влияние:** Потенциальный `NullReferenceException` в runtime, если `user` окажется `null` при вызове `UserManager.IsInRoleAsync`. Однако в контексте контроллеров, где `User` уже аутентифицирован, риск низкий.
- **Частота и слой:** 6 вхождений в слое **Backend API** (контроллеры):
  - `CoursesController.cs` — 4 предупреждения (строки 84, 85, 202, 203)
  - `TasksController.cs` — 2 предупреждения (строки 35, 36)
- **Трудоемкость устранения:** Низкая. Требует добавления null-проверки или использования null-forgiving operator (`!`) в 6 местах. Пример фикса:
  ```csharp
  var user = await _userManager.GetUserAsync(User) ?? throw new InvalidOperationException("User not found");
  // или
  await _userManager.IsInRoleAsync(user!, "Manager")
  ```

---

#### 2. **CS8625: Литерал, равный NULL, не может быть преобразован в ссылочный тип, не допускающий значение NULL**
- **Суть:** Присваивание `null` свойствам, которые объявлены как non-nullable reference types.
- **Влияние:** Предупреждение компиляции в тестах; не влияет на работу приложения, но указывает на несоответствие типов в тестовых данных.
- **Частота и слой:** 8 вхождений в слое **Tests** (тестовый проект):
  - `TasksControllerTests.cs` — строка 30 (повторяется 8 раз для разных параметров)
- **Трудоемкость устранения:** Низкая. Требует корректировки тестового кода (изменение типов DTO на nullable или корректировка тестовых данных). Пример фикса:
  ```csharp
  // Было (в тесте):
  new LoginRequest { Email = null, Password = null }
  // Стало (если DTO позволяет):
  new LoginRequest { Email = string.Empty, Password = string.Empty }
  // Или изменить LoginRequest.Email на string?
  ```

---

#### 3. **NU1903: Package 'System.Security.Cryptography.Xml' 9.0.0 has a known high severity vulnerability**
- **Суть:** Использование версии пакета с известной уязвимостью высокой степени серьезности (ссылка: https://github.com/advisories/GHSA-37gx-xxp4-5rgx).
- **Влияние:** Потенциальная атака через уязвимость в криптографических функциях. Затрагивает безопасность приложения.
- **Частота и слой:** Появляется при каждой сборке для всех проектов, зависящих от этого пакета (прямо или косвенно):
  - `TeachAssist.Domain` (косвенная зависимость)
  - `TeachAssist.Api` (косвенная зависимость)
  - `TeachAssist.Api.Tests` (косвенная зависимость)
- **Трудоемкость устранения:** Средняя. Требует:
  1. Проверки наличия обновленной версии пакета (например, 9.0.1+).
  2. Обновления пакета во всех проектах (или добавления прямой зависимости с нужной версией).
  3. Проверки совместимости с остальными зависимостями (возможны конфликты версий).
