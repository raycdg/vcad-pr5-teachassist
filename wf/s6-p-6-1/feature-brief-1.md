# Feature Brief: назначить/снять преподавателя с дисциплины/курса через UI

## Цель
- менеджер из интерфейса может посмотреть, какие преподаватели назначены на дисциплины и курсы
- менеджер из интерфейса может назначить/снять преподавателя с дисциплины/курса

## Контекст
- в frontend нет страниц просмотра назначенных преподавателей на курс и на дициплину
- в backend имеется API для этих действий

## Инварианты
- в UI не должны меняться другие страницы
- в БД никаких изменений

## Не входит в проход
- не делать никакого рефакторинга.

## Критерии готовности
- у менеджера в интерфейсе имеются возможности назначить/снять преподавателя с дисциплины
- у менеджера в интерфейсе имеются возможности назначить/снять преподавателя с курса
- все существующие тесты зеленые
- линтер без ошибок
