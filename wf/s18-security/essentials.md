## Блокировка на уровне инструмента

Чувствительных файлов в проекте нет, но для практики запретим агенту читать файлы *.prompt (это заготовки запросов для работы, там нет ничего секретного, но они ему все равно не нужны).

В файле opencode.json добавим:

```json
{
    "permission": {
        "read": {
            "*.prompt": "deny"
        }
    }
}
```

Проверим, что защита работает:

```text
Прочитай файл wf\s5\1.prompt и сделай краткое резюме его содержимого
```

Агент отказывается читать. Но если указать явно:

```text
Прочитай файл @wf\s5\1.prompt и сделай краткое резюме его содержимого
```

В таком случае он успешно читает. 

В документации opencode сказано, что ограничения работают только для самостоятельных действий агента. Если пользователь явно указывает читать, то ограничения обходятся.
