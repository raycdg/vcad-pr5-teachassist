# Команда ревью изменений перед коммитом — TeachAssist

> **Назначение**: Набор команд для проверки изменений перед созданием коммита.
> **Версия**: 1.0 | **Дата**: 2026-05-06

---

## Когда использовать

- Перед каждым коммитом, особенно после исправлений и рефакторинга
- Для быстрой проверки состояния рабочего дерева (W2, W4)
- При подозрении на незапланированные изменения

---

## Команда

Выполни в корне проекта:

```powershell
# 1. Состояние рабочего дерева (новые/изменённые/удалённые файлы)
git status

# 2. Детальный diff всех изменений (unstaged + staged)
git diff; if ($LASTEXITCODE -eq 0) { git diff --cached }

# 3. Краткий diff в виде списка файлов со статистикой
git diff --stat; if ($LASTEXITCODE -eq 0) { git diff --cached --stat }

# 4. Проверка: нет ли изменений в миграциях БД (запрещено без разрешения)
git diff --name-only | Select-String 'backend/migrations/'

# 5. Проверка: нет ли подозрительных файлов (секреты, ключи)
git diff --name-only | Select-String '\.env|\.pem|\.key|secrets'
```

**Быстрая версия** (если уверен, что migrations и секреты не затронуты):

```powershell
git status; if ($LASTEXITCODE -eq 0) { git diff --stat; git diff --cached --stat }
```

---

## Что проверить по результатам

После выполнения команд:

- [ ] В `git status` — только ожидаемые файлы в списке изменений
- [ ] В `git diff` — нет неожиданных изменений в соседних файлах
- [ ] Проверка миграций (пункт 4) — **пустой вывод** или изменения были согласованы
- [ ] Проверка секретов (пункт 5) — **пустой вывод**
- [ ] Изменения соответствуют цели коммита
