# Checklist приёмки результатов — TeachAssist

> **Назначение**: Универсальный чеклист для приёмки исправления ошибки или рефакторинга.
> **Версия**: 1.0 | **Дата**: 2026-05-06

---

## Когда использовать

- После завершения исправления бага (W2)
- После завершения рефакторинга (W4)
- Перед созданием коммита, для финальной проверки

---

## Checklist

### Сборка и тесты

- [ ] `dotnet build` — проходит без ошибок и новых warnings
- [ ] `dotnet test` — все тесты зелёные, без регрессий
- [ ] `npm run lint` — проходит без ошибок (если затронут frontend)

### Backend (если затронут)

- [ ] HTTP-статусы ответов не изменились
- [ ] Формат JSON-ответов сохранён (совместимость API)
- [ ] Нет изменений в `backend/migrations/` (без явного разрешения)
- [ ] Все исключения обрабатываются

### Frontend (если затронут)

- [ ] Все существующие маршруты доступны
- [ ] Используются только компоненты из официального Vuetify 3 API
- [ ] Правила валидации форм сохранены
- [ ] Нет eslint-ошибок и предупреждений

### Документация и процесс

- [ ] `docs/` обновлён, если затронут пользовательский функционал
- [ ] Изменения не нарушают ограничения из `AGENTS.md`
- [ ] Приоритеты соблюдены: надёжность > проверяемость > читаемость

### Финальная проверка

- [ ] `git diff` — изменены только ожидаемые файлы
- [ ] Нет закоммиченных секретов, ключей, токенов
- [ ] Commit message соответствует формату проекта (префикс + описание «почему»)
