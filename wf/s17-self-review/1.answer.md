## План реализации: Экспорт прогресса группы в Excel

### Обзор

Функция экспорта данных прогресса курса в Excel-файл с заголовком (предмет, группа, дата/время) и таблицей студентов с оценками по заданиям.

### Архитектурное решение

**Backend-генерация** — файл генерируется на сервере и возвращается как `FileResult` с заголовком `Content-Disposition: attachment`. Это соответствует инварианту "не добавляется новых слоев" — добавляем один метод в существующий контроллер.

**Библиотека**: ClosedXML (простой API, хорошая поддержка .NET, не требует Excel на сервере).

---

### Шаги реализации

#### 1. Backend: Добавить пакет ClosedXML

- **Файл**: `backend/TeachAssist.Api.csproj`
- **Изменение**: Добавить `<PackageReference Include="ClosedXML" Version="0.104.2" />`

#### 2. Backend: Новый endpoint экспорта

- **Файл**: `backend/Api/Controllers/CoursesController.cs`
- **Изменение**: Добавить метод `ExportProgress(int id)`
- **Маршрут**: `GET /api/courses/{id}/export-progress`
- **Логика**:
  1. Повторно использует логику получения данных из `GetProgress` (студенты группы, задания дисциплины, оценки)
  2. Создает Workbook через ClosedXML
  3. Строит лист:
     - Строки 1-3: заголовок (предмет, группа, дата/время)
     - Строка 5: шапка таблицы — № пп, Фамилия Имя, затем задания по порядку
     - Строки 6+: данные студентов с оценками
  4. Возвращает `FileStreamResult` с `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`

#### 3. Frontend: Кнопка экспорта

- **Файл**: `frontend/src/views/CourseProgress.vue`
- **Изменение**: Добавить кнопку "Экспорт в Excel" рядом с существующими элементами управления
- **Логика**:
  - Вызов `axios.get(`/api/courses/${courseId}/export-progress`, { responseType: 'blob' })`
  - Создание временной ссылки для скачивания blob-объекта
  - Триггер скачивания через программный клик

#### 4. Тесты: Smoke-тест экспорта

- **Файл**: `tests/TeachAssist.Api.Tests/CourseControllerTests.cs`
- **Изменение**: Добавить тест `ExportProgress_ReturnsExcelFile`
- **Проверяет**:
  - Возвращается `FileContentResult`
  - ContentType = правильный MIME-тип
  - Файл не пустой

### НЕ затрагиваются

- Миграции БД
- Модели домена
- DTO (используем существующие или читаем напрямую из DbContext)
- Структура БД
- Существующие endpoint'ы
- Другие контроллеры
- Роутер

### Риски и ограничения

- ClosedXML добавляет зависимость, но это стандартная библиотека, не новый "слой" архитектуры
- Дублирование логики получения данных из `GetProgress` — минимальное, вынесем в приватный метод если нужно
- Фронтенд не требует новых библиотек — скачивание blob нативное
