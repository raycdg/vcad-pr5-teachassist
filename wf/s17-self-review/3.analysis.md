# Анализ self-review агента

## Основные проблемы

|Находка|Паттерн|Серьёзность|
|---|---|---|
|DateTime.Now для даты в файле и имени файла|Несоответствие конвенции проекта|Низкая, в большинстве случаев не выявится|
|Range Excel при 0 студентов|Молчащая ошибка|Средняя, вместо пустой таблицы - коверканный заголовок|
|CORS-заголовок при скачивании файла|Молчащая ошибка|Средняя, имя файла не будет понятным (если их много в downloads, то не найти)|

## Предполагаемые решения

1. В brief-шаблон (или правила) для проекта добавить: `для даты/времени всегда использовать DateTime.UtcNow`
   Сделать короткий багфикс в текущей реализации: исправление на DateTime.UtcNow
2. Сделать короткий багфикс в текущей реализации: добавить проверку `if (students.Count > 0)`
3. Сделать короткий багфикс в текущей реализации: явно задать `Access-Control-Expose-Headers: Content-Disposition`
