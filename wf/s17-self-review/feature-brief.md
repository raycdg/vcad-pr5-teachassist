# Feature brief

## Цель 
Нужно сделать экспорт прогресса группы студентов в файл Excel

## Сценарий
Пользователь (преподаватель, манеждер, админ) на странице прогресса курса нажимает кнопку `Экспорт в Excel`.
Текущий прогресс всех студентов группы загружается из БД, генерируется файл.
В файле нужен заголовок (предмер, группа, текущие дата/время), таблица с полями: № пп, фамилия + имя, далее все задания по курсу в порядке их номеров, каждый в отдельной колонке.
В строках таблицы заполняется студентами и их оценками по соответствующим заданиями.
Файл скачивается через браузер.
Для созданного функционала нужно добавить минимальные smoke-тесты.

## Контекст
- frontend: cтраница прогресса курса.
- backend: контроллер курса.

## Инварианты
- существующий функционал страницы курса остается неизменным
- не добавляется новых слоев, универсальных фабрик экспорта и подобного
- не изменяется структура БД

## Не входит в проход
- редизайн страниц
- рефакторинг контроллера
- интеграционное тестирование
- настройки экспорта
- соседние изменения

## Критерий готовности
- анализ кода показывает, что проектируемый пользовательский сценарий выполним
- не затронуты сторонние артефакты, слои, не введены новые архитектурные решения и т.п.
- тесты зеленые, включая созданные
