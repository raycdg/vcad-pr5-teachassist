# MVP проекта

## Основная ценность
TeachAssist — веб-приложение для помощи преподавателю в контроле за выполнением заданий и аттестации. 

Приложение должно дать возможность:
- заводить группы студентов
- добавлять студентов к группе
- заводить список учебных предметов
- добавлять перечень контрольных заданий и аттестаций к предметам (два варианта выполнения: выполнено/не выполнено, с оценкой от 0 до N баллов)
- прикреплять группы студентов к предметам, которые обучаются в текущий момент
- отмечать выполнение студентом заданий и аттестаций, выставлять оценки за задания и аттестации, просматривать прогресс студентов
- уведомлять студентов по электронной почте о получении оценки
- закрывать обучение группы студентов по предмету, делая работу с учебым курсом неактивным

## Ключевой сценарий
Преподаватель:
1. Создает группу и заводит в нее студентов
2. Создает учебный предмет и заполняет его списком заданий 
3. Создает учебный курс (сопоставляет с группой студентов предмет, прогресс выполнения заданий которого будет отмечаться у студентов группы)
4. Отмечает выполнение студентом задания (да/нет либо ставит оценку в баллах), студенту по электронной почте автоматически отправляется письмо с уведомлением о получении оценки
5. Просматривает прогресс группы студентов по предмету
6. Закрывает учебный курс

## Пока не входит в MVP
- авторизация и личный кабинет преподавателя
- авторизация и личный кабинет студентов
- уведомления в приложении
- расписание занятий, напоминания о предстоящих занятияъ
- учет посещения студентами занятий
- автоматический расчет аттестаций и надбавок по выполненным заданиям
- аналитика и отчеты

# Путь к MVP

## Исходное состояние
По результатам предыдущих практический заданий уже создан минимальный каркас прииложение, в котором имеется:
- Список групп (CRUD), для группы задается: название, сокращение, год начала обучения
- Список студентов группы (CRUD), для студента задается: имя, фамилия, группа, email
- Главная страница с дашбордом и навбаром

## Итерация 1
Следующим срезом в проект добавляется список учебных предметов и заданий к ним.

Для предмета задается: название, сокращение. Функционал CRUD.

Для заданий задается: название (например, `Лаб.раб.№1`, `Надбавка за активность`), порядковый номер, тип оценки (`Зачёт/незачет`, `Бальная`), максимальный балл. Функционал CRUD плюс изменение порядкового номера.


## Итерация 2
Следующим срезом в проект добавляется список учебный курсов и заполнение прогресса студентов.

Для учебного курса задается: предмет, группа, год обучения, активен. Функционал CRUD плюс `Сделать активным`/`Сделать неактивным`. У неактивного курса нельзя редактировать оценки студентов. По умолчнию в списке курсов отображаются только активные курсы. При нажатии кнопки `Показать все курсы`/`Скрыть неактивные` переключается отображение неактивных курсов.

На странице прогресса студентов выводится полный список группы (студенты отображаются по строкам), по столбцам отображаются задания предмета. При горихонтальном скроллировании колонка с фамилией и именем студента фиксирована. на странице есть фильтрация студентов по фамилии и имени. Сортировка по фамилии и имени.
В таблице ячейки являются редактируемыми, в них можно ввести оценку. После ввода всех оценок нужно нажать на кнопку `Сохранить`, что записать в БД все изменения.


## Итерация 3
Интеграция с почтовым сервером для отправки уведомления студенту на его email о получении оценки


## Итерация 4
Скрипт автоматизации загрузки списка студентов из файла Excel


## Сигнал, что MVP уже есть
Ключевой сценарий работает целиком, если можно пройти по нему от начала до конца, в том числе смоделировать работу преподавателя при проставлении оценок нескольким студентам.
