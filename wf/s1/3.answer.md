### 3. План выполнения
1. **Backend: Сущности и контекст данных**
   - Создать `Course` (связи с Subject, Group, поля Year, IsActive) и `StudentGrade` (связи с Student, Assignment, Course, поле Value для оценки).
   - Обновить `AppDbContext`: добавить `DbSet<Course>` и `DbSet<StudentGrade>`, настроить связи.
2. **Backend: API контроллер**
   - Реализовать CRUD для курсов в `CourseController`.
   - Добавить эндпоинт переключения статуса активности (`PATCH /api/courses/{id}/toggle-status`).
   - Добавить эндпоинт получения данных прогресса (`GET /api/courses/{id}/progress`) и пакетного сохранения оценок (`POST /api/courses/{id}/grades`).
3. **Backend: Тесты**
   - Написать тесты для всех эндпоинтов контроллера, включая проверку блокировки редактирования оценок для неактивных курсов.
4. **Frontend: Маршрутизация и навигация**
   - Добавить маршруты: `/courses` (список), `/courses/create`, `/courses/:id/edit`, `/courses/:id/progress`.
   - Добавить пункт «Курсы» в навбар.
5. **Frontend: Страницы курсов**
   - Реализовать список курсов с переключателем отображения активных/всех курсов.
   - Реализовать форму создания/редактирования курса (выпадающие списки для существующих предметов и групп).
6. **Frontend: Страница прогресса**
   - Реализовать таблицу с фиксированной колонкой студентов, столбцами-заданиями.
   - Добавить фильтрацию по имени студента, сортировку по фамилии.
   - Реализовать локальное хранение несохраненных оценок и кнопку «Сохранить» для пакетной отправки.
7. **Проверка**
   - Запустить тесты бэкенда, исправить ошибки.
   - Запустить линтер фронтенда, исправить ошибки.
