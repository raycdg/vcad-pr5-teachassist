## План реализации: Disciplines

### 1. Точка встраивания

- **Backend**: новые файлы рядом с существующими `GroupsController.cs`, `Group.cs`, `GroupDtos.cs`
- **Frontend**: новые файлы рядом с `views/Groups.vue`, `stores/groups.js`, маршрут в `router/index.js`, кнопка в `App.vue`, карточка в `Dashboard.vue`

### 2. Минимальный набор файлов

| # | Файл | Назначение |
|---|------|------------|
| 1 | `backend/domain/Models/Discipline.cs` | Модель сущности (Id, Name, Abbreviation) |
| 2 | `backend/api/DTOs/DisciplineDtos.cs` | DTO: DisciplineDto, CreateDisciplineDto, UpdateDisciplineDto |
| 3 | `backend/domain/Data/AppDbContext.cs` | **изменить** — добавить `DbSet<Discipline>` и fluent-конфигурацию |
| 4 | `backend/api/Controllers/DisciplinesController.cs` | CRUD-контроллер |
| 5 | `backend/migrations/*` | **новая миграция** (создаётся через `dotnet ef`) |
| 6 | `frontend/src/stores/disciplines.js` | Pinia store (fetch, create, update, delete) |
| 7 | `frontend/src/views/Disciplines.vue` | Страница с таблицей, диалогами создания/редактирования/удаления, фильтром |
| 8 | `frontend/src/router/index.js` | **изменить** — добавить маршрут `/disciplines` |
| 9 | `frontend/src/App.vue` | **изменить** — кнопка «Disciplines» в навбаре после Groups |
| 10 | `frontend/src/views/Dashboard.vue` | **изменить** — ссылка/карточка Disciplines в дашборде |

### 3. План из 5 шагов

**Шаг 1 — Backend модель и DTO**
Создать `Discipline.cs` (Id, Name, Abbreviation), `DisciplineDtos.cs` (3 DTO с `[Required]`/`[MaxLength]` для Name и Abbreviation).

**Шаг 2 — DbContext и миграция**
Добавить `DbSet<Discipline>` в `AppDbContext.cs`, fluent-конфигурацию таблицы `disciplines`. Сгенерировать миграцию `dotnet ef migrations add AddDisciplines`.

**Шаг 3 — Backend контроллер**
Создать `DisciplinesController.cs` по образцу `GroupsController.cs`: GET (все), POST, PUT, DELETE, валидация уникальности Name.

**Шаг 4 — Frontend store и страница**
Создать `stores/disciplines.js` (axios CRUD), `views/Disciplines.vue` (v-data-table, v-dialog для CRUD, текстовый фильтр по name/abbreviation) по образцу `Groups.vue`.

**Шаг 5 — Навигация и роутинг**
Добавить маршрут `/disciplines` в `router/index.js`, кнопку в навбар `App.vue` после Groups, карточку в `Dashboard.vue`.

### 4. Риски расползания scope

| Риск | Как ограничить |
|------|----------------|
| Связывание дисциплин с группами/студентами/заданиями | Явно исключить из текущего прохода (указано в brief) |
| Добавление дополнительных полей (описание, кафедра, часы) | Только Name + Abbreviation как в brief |
| Пагинация, сортировка, серверная фильтрация | Быстрая клиентская фильтрация по строке — достаточно для MVP |
| Рефакторинг существующего кода (DRY, shared components) | Не трогать, копировать паттерн Groups as-is |
| Покрытие тестами | Явно исключено из brief |
