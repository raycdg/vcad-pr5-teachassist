## What I do

- Collect test coverage
- Read test code
- Analyse covered code, spot files/functions with strong/medium/weak coverage
- Analyse uncovered code, spot files/functions with first/second/last priority
- Summarize a report for covered and uncovered code

## When to use me

Use this when you are tasked with test coverage questions. 
Ask clarifying questions if the priority decision is unclear.
