## When to use

Используй этот скил, когда пользователь просит сделать code review с внешним отчетом или глобальным отчетом или сохранить отчет во внешнюю папку по отношению к проекту.
Не используй этот скил для задач code review, когда не требуется делать внешний отчет.

## Inputs
1. Область для code review, один из вариантов:
- один или несколько файлов, для которых сделать code review
- указание области (уровня, каталога и т.д.), для которых сделать code review
- если ничего не указано, то code review нужно сделать для изменений в текущем diff
2. Имя файла отчета для результата. Если имя файла не указано, то файл должен называться `code-review-` + текущие дата и время + `.md`. Если не указан путь сохранения, то нужно сохранить в первый из доступных для MCP Filesystem каталогов.

## What to do

1. Определи границы области (конкретный список файлов), для которых необходимо выполнить code review.
2. Выполни code review полученной области и составь перечень предложений.
3. Составь отчет по code review.
4. Отчет сохрани в файл во внешнем каталоге по отношению к каталогу проекта. Используй MCP Filesyste.
5. Выдай краткий ответ:
- сколько предложений включает отчет
- сколько файлов он затрагивает
- по какому пути и с каким именем файла он сохранен

## Constraints
- используй MCP Filesystem только для работы с внешними каталогами, для работы с файлами внутри каталога проекта используй встроенные инструменты
- запрещено изменять любые файлы в каталоге проекта и его подкаталогах
- запрещено использовать любыз другие MCP, кроме Filesystem

## Stop signals
- `filesystem_write_file` или `filesystem_edit_file` или `filesystem_read_file` недоступны - сразу стоп
- не указано, для чего делать code review, в текущем контексте нет кода последней задачи - сразу стоп
